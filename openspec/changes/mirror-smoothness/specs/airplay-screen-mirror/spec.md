# Spec Delta

## Purpose

接收 iPhone/iPad 的 AirPlay 屏幕镜像，在电视上实时渲染设备屏幕内容，并保证镜像卡顿可被日志诊断、接收端不引入额外卡顿。

## ADDED Requirements

### Requirement: 镜像卡顿可诊断
系统 SHALL 在镜像期间以固定间隔输出帧到达数、渲染数、队列深度与丢帧数的聚合指标，使运维人员能够从日志判断卡顿发生在发送端还是接收端。

#### Scenario: 发送端降帧
- **WHEN** iPhone 发送帧率下降而电视端队列深度保持低位
- **THEN** 日志显示到达数与渲染数同步下降
- **AND** 队列深度不持续增长

#### Scenario: 接收端处理慢
- **WHEN** 电视端解码或渲染跟不上帧到达速度
- **THEN** 日志显示队列深度持续增长或丢帧数大于零

### Requirement: 接收端不引入额外卡顿
当 iPhone 按稳定帧率发送镜像视频时，系统 SHALL 及时解码并渲染每一帧，不因接收端处理能力造成持续丢帧或画面冻结。

#### Scenario: 稳定帧率渲染
- **WHEN** iPhone 以 30fps 或以上稳定发送镜像帧
- **THEN** 电视端渲染帧数与到达帧数一致
- **AND** 不出现解码器反复重建
