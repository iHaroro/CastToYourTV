- [ ] DLNA：手机投屏列表能搜到设备，投放视频自动播放，支持快进/暂停/比例调整
- [ ] AirPlay 镜像：iPhone 屏幕镜像列表能搜到设备，免 PIN 连接，画面实时渲染
- [ ] AirPlay 音乐：iPhone 隔空播放列表能搜到设备，出声正常，播放页展示封面/曲名/时长/音量/设备信息
- [ ] 服务：App 后台/重启后服务仍运行，首页自检显示三项状态，投放时自动拉起播放页
